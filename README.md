# 🌟 Universal Spiritual Academy

> **Multi-Faith Moral Wisdom & Character Education for Children with Integrated Parent Analytics.**

An interactive, responsive web application designed to introduce children to universal ethical values (Compassion, Truth, Peace, Equality, Selfless Service) found across major world religions (Buddhism, Hinduism, Sikhism, Christianity, Islam, Jainism, Judaism).

---

## ✨ Key Features

### 🧒 1. Student Portal (Gamified Learning for Kids)
* **World Wisdom Realms:** Interactive cards for 7 major world religions featuring sacred symbols, progress bars, and virtue tags.
* **🎬 Video Lectures:** Animated lessons with playlists, playback controls, and auto-attendance tracking (+20 Virtue Stars).
* **📚 Moral Storybooks:** Illustrated flipbooks with read-aloud voiceover and distinct moral takeaways.
* **💡 Core Teachings & Flipcards:** 3D interactive flipcards connecting spiritual concepts to relatable, real-life child examples.
* **🧘 Mindful Calm Zone:** 2-minute visual breathing sphere (*Inhale... Hold... Exhale*) paired with authentic Tibetan singing bowl chimes.
* **📝 Assessment & Certification:** Chapter quizzes and final graded exams with downloadable **Certificates of Wisdom & Ethics**.

### 👨‍👩‍👧 2. Parent Monitoring Portal
* **Child Profile Switcher:** Seamlessly toggle between multiple enrolled children.
* **Executive Metrics:** Weekly study hours logged, average test scores (e.g. 94% A+), lectures attended, and active streak.
* **🎥 Lecture Attendance Checklist:** Video-by-video status verification (Completed vs. Pending) with timestamps.
* **📊 Weekly Learning Hours Graph:** Interactive 7-day bar chart showing study minutes from Monday to Sunday.
* **🏆 Exam Scorecards:** Performance badges, letter grades, and direct certificate access.
* **💬 Family Dinner Prompts:** Thoughtful moral questions for parents to discuss at home with a *"Mark as discussed"* toggle.

---

## 🛠️ Technology Stack

* **Frontend:** Vanilla CSS (Glassmorphism, CSS Custom Properties, 3D Transforms) & Modern JavaScript (ES Modules).
* **Build Tool:** [Vite](https://vitejs.dev/) for blazing-fast development and optimized production bundles.
* **Audio FX:** Web Audio API (Synthesizing Tibetan singing bowls, temple bells, and harp chimes natively).
* **Animations & Confetti:** `canvas-confetti` and CSS Keyframe animations.
* **Icons:** [Lucide Icons](https://lucide.dev/).
* **Documents:** Automated Word (`.docx`) and PDF generation pipeline included.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/RUDRA-2612/Spritual_Tech.git
cd Spritual_Tech
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
